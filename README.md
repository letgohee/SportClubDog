# SportClubDog — календар тренувань у Telegram

Telegram-бот для тренера: записуйте клієнток на тренування з датою, часом і способом оплати (🧾 чек чи 💵 готівка).

## Що вміє бот

| Кнопка / команда | Що робить |
|---|---|
| ➕ Додати запис (`/add`) | Календар → час (кнопкою або текстом, напр. `18:15`) → ім'я клієнтки (або вибір з недавніх) → чек / готівка |
| 📅 Календар (`/calendar`) | Місячний календар, дні з тренуваннями позначені `•`. Натисніть день, щоб побачити записи, видалити або додати новий |
| 📋 Сьогодні (`/today`) | Розклад на сьогодні |
| 📊 Звіт за місяць (`/report`) | Скільки тренувань, скільки оплат чеком і готівкою, розбивка по клієнтках |
| `/client Олена` | Історія тренувань однієї клієнтки |
| `/cancel` | Скасувати введення |

Кожен користувач бачить лише свої записи. Дані зберігаються у файлі SQLite (`data/sessions.db`).

## Запуск

1. У Telegram напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → отримайте токен.
2. Скопіюйте `.env.example` у `.env` і вставте токен у `BOT_TOKEN`.
3. (Рекомендовано) Щоб ботом користувались лише ви — запустіть бота, напишіть йому будь-що
   з порожнім `ALLOWED_USER_IDS`, дізнайтесь свій ID (напр., через [@userinfobot](https://t.me/userinfobot))
   і впишіть його в `ALLOWED_USER_IDS`.

### Локально (Python 3.11+)

```bash
pip install -r requirements.txt
python -m bot.main
```

### Через Docker (для сервера)

```bash
docker build -t sportclubdog .
docker run -d --name sportclubdog --restart unless-stopped \
  --env-file .env -v $(pwd)/data:/app/data sportclubdog
```

Бот має працювати постійно, тому для щоденного користування його варто запустити на сервері
(будь-який недорогий VPS, Railway, Render, Fly.io тощо). Не забудьте зберігати папку `data/` — там уся база.
